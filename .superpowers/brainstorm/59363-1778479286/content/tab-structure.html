Tabbed Dashboard — 分頁結構

以日常監控的使用頻率排列

Proposed 5 Tabs

1

Overview

Health strip（精簡版）+ Alerts + Token Usage 概要
一進入就看到 cluster 是否正常

2

Cluster

合併 Nodes + GPU Usage + Workers + Model Registry 為一個 view
目前分散在 4 個 table 的資訊一次掌握

3

Providers

Provider health cards + routing controls + metrics + overrides + audit log
跟現在一樣但獨立分頁

4

Charts

所有圖表集中在這頁，不再跟其他內容搶空間
保留 Health/Traffic/Hardware 分頁籤

5

System

GPU OS + Runtime Systems（multi-agent, security, observability）
需要才去看的底層狀態

移至次要 / 可折疊

Task Queue、Error Codes、Endpoint Latency → 放在某個 tab 底部可折疊區塊，不佔日常視線

這樣的 tab 結構你覺得如何？有想調整的嗎？
