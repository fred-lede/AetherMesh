Three Approaches

Dashboard layout rethink for daily monitoring

A

Consolidate & Collapse

Merge related tables (Nodes + GPUs + Workers + Models → "Cluster" section), collapse diagnostics (Error Codes + Endpoint Latency) as expandable. Token Usage → mini chart. Charts keep. Less scrolling.

B

Tabbed Dashboard

Horizontal tabs: Overview | Cluster | Providers | Charts | Admin. Each tab focused and scannable. No vertical scrolling within each tab.

C

Summary-First

Top half = summary KPIs + sparkline charts (one viewport). Bottom half = expandable detail sections. Only expand what you need.
